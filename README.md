# 🧪 qa-ai-lab

My hands-on lab on the path to becoming a **QA specialist in test automation and AI**.
I'm a Senior QA Engineer, and this repo documents a 6-month study plan in public:
code, tests and lessons learned.

## 🎯 Goals
- Strengthen software engineering foundations for testing (Python, algorithms, design patterns)
- Build a test automation framework (UI + API + contract) running in CI
- Apply AI to testing and learn how to test AI systems (LLMs, chatbots)

## 🛠️ Stack
Python 3.14 · pytest

*(more tools will be added as the plan evolves: Playwright, GitHub Actions, k6, Docker)*

## 🗺️ Roadmap
- [ ] Month 1 – Engineering foundations: Python, pytest, algorithms, design patterns
- [ ] Month 2 – Advanced automation: Playwright, API and contract testing, CI
- [ ] Month 3 – Performance, Docker, cloud and basic security
- [ ] Month 4 – AI applied to testing
- [ ] Month 5 – Testing AI systems (LLM evaluation, prompt injection)
- [ ] Month 6 – Interview preparation

## 📁 Structure

qa-ai-lab/
├── src/ # code under test
└── tests/ # automated tests


## ▶️ How to run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest
```
